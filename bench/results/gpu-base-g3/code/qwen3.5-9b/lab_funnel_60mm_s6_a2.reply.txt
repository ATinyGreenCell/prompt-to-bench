Let's trace:
Profile point `(x, y)`.
Rotate around Z axis.
The resulting point is `(x*cos(theta) - y*sin(theta), x*sin(theta) + y*cos(theta), y)`.
So the Z coordinate of the resulting object is the Y coordinate of the profile.
The radius of the resulting object at height Z is the X coordinate of the profile at that Y.
So to make a cone from `z=0` to `z=height`:
We need the profile to go from `y=0` to `y=height`.
At `y=0`, radius `x=0`.
At `y=height`, radius `x=radius_top`.
So the profile is a line from `(0,0)` to `(radius_top, height)`.
This creates a cone with height `height` and top radius `radius_top`.

The `rotate_extrude` will create the cone. Then we need to translate it by `z=20`.

```openscad
// Lab Funnel Design
// Units: millimetres
// Orientation: Upright, wide opening at top, rests on XY plane at z=0.

// --- Dimensions ---
// Spout (Tube)
$spout_outer_diameter = 10;
$spout_inner_diameter = 6.8; // 10 - 2*1.6
$spout_length = 20;

// Cone (Funnel Body)
$cone_bottom_diameter = 10; // Matches spout outer diameter
$cone_top_diameter = 60;
$cone_height = 30; // From z=20 to z=50

// Wall Thickness
$wall_thickness = 1.6;

// Resolution for smooth curves
$fn = 128;

// --- Helper Functions ---

// Creates a hollow cylinder (tube)
module hollow_cylinder(outer_d, inner_d, height) {
    difference() {
        cylinder(h = height, d = outer_d, $fn = $fn);
        cylinder(h = height, d = inner_d, $fn = $fn);
    }
}

// Creates a hollow cone (frustum)
// bottom_d: diameter at the smaller end (attached to spout)
// top_d: diameter at the larger end (rim)
// height: vertical height of the cone
module hollow_cone(bottom_d, top_d, height) {
    difference() {
        // Outer Cone
        rotate_extrude(angle = 360) {
            // Profile in XY plane:
            // X = radius, Y = height (which becomes Z in the extruded object)
            // Start at (radius_bottom, 0), end at (radius_top, height)
            polygon(points = [
                [bottom_d/2, 0],
                [top_d/2, height]
            ]);
        }
        
        // Inner Cone (Hole)
        rotate_extrude(angle = 360) {
            inner_bottom = bottom_d - $wall_thickness * 2;
            inner_top = top_d - $wall_thickness * 2;
            
            polygon(points = [
                [inner_bottom/2, 0],
                [inner_top/2, height]
            ]);
        }
    }
}
