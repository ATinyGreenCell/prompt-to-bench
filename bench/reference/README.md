# Benchmark reference solutions (frozen, v1)

These 16 files are the answer keys of Prompt-to-Bench-16: each is exactly the part its
prompt in `../tasks.yaml` describes, and the hidden checks and `../reference_stats.json`
were built from them. **Do not edit them** - every published score depends on them.

They test whether a model can follow a written specification. They are not the
recommended lab parts: the printable, lab-ready versions live in [`designs/`](../../designs/)
and differ where an audit found a better choice for real use (wider tube clearances,
safer gel-tank electrodes, standoffs for the stirrer magnets, and so on; see
`meta/audits/2026-10-06_mechanical_and_biological.md`).
